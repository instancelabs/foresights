Advanced tips & tricks

Refreshed periodically

Pin aws-cdk CLI and aws-cdk-lib together — Drift is the #1 source of works-on-my-machine

The CLI bumps minor versions independently of the lib. Pin both.

Use iam.PolicyStatement over inline JSON — Type-checks at synth

Inline JSON skips the type check. The L2 catches typos.

new iam.PolicyStatement({
  actions: ['s3:GetObject'],
  resources: [bucket.arnForObjects('*')],
})

cdk diff before every PR — Synth surprises are real

A bumped aws-cdk-lib version can change generated logical IDs subtly.
