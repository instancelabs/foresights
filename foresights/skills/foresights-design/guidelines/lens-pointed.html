Lens, made pointed

Four ways to sharpen the emitted arc into a forward point — leaning into fore-sight: the node doesn't just receive, it aims ahead. All keep the 3 directional source nodes feeding one focal node.

The play: "sight" → an aiming point / sightline arrow. Two angular takes (caret, arrowhead) and two that keep a curved, tapered "comet" point so it still feels like a sweep.
L1

Caret

24px

An open caret › fires forward off the focal node — "what's next," lightweight and unmistakably forward.

Distinct: open chevron = the same "forward" affordance used in the UI. Airy, scales well.

Sightline

24px

A true sightline: the focal node fires a shaft + arrowhead dead ahead. Sources converge, then the eye looks forward.

Distinct: the literal "line of sight" arrow nails the name; reads as aim/direction, never as a feed glyph.
L3

Comet

24px

The emitted arc tapers to a sharp tip — a comet/swoosh that still curves, so it keeps the radar-sweep feel while ending in a point.

Distinct: curved + pointed = a sweep with intent. Softest, most "motion," bridges the sweep idea.
L4

Eye-point

24px

The focal node opens into an eye — a lens shape pointed at both ends — with the convergence flowing into it. Foresight, made literal.

Distinct: a pointed eye/lens is the strongest pun on "sight," and the pointed ends are inherent to the shape.
