Making it ours

Both shortlisted marks live in crowded, generic territory — Sweep overlaps the universal RSS/sonar glyph; Constellation is the stock "network" visual. These reworks keep each core idea but break the cliché so the mark reads as Foresights, not a feed icon or a clip-art graph.

How to read this: each variant shows the mark at hero (62px) and favicon (24px) size, with a note on what specifically makes it distinct. My picks are flagged — but the call is yours.

Sweep — reworked was: reads as RSS

The trap is the corner-dot-plus-concentric-arcs — that's the RSS feed icon exactly. Each of these keeps "forward detection" but kills the stacked-arcs-from-a-corner read.

pick
S1

Sightline

24px

A horizontal sightline travels left→right and lands on a single focal node; one faint arc behind it implies the signal.

Distinct: the through-line + single node is a "line of sight," not arcs from a corner. Favicon collapses to a clean line→dot.
S2

Resolve

24px

One continuous arc spirals inward and resolves onto the node — the distant thing brought into focus, in a single gesture.

Distinct: one stroke, not stacked concentric arcs. Reads as an aperture/eye closing on a point.
S3

Lookahead

24px

Forward chevrons step toward the node — fast-forward, "what's next," looking ahead. Angular, not curved.

Distinct: chevrons are unmistakably "forward/next," nothing like the rounded RSS waves.
S4

Signal-F

24px

An F monogram whose two arms curve out as signal arcs — merges the product letterform with the radar idea.

Distinct: anchored to the letter F, so it can't be mistaken for a generic feed glyph. Most ownable.

Constellation — reworked safer base

Generic "nodes + lines" is everywhere. The fix: make the convergence intentional and directional — clear source nodes feeding one emphasized focal node — and vary the node weights so it reads as a system, not clip-art.

pick
C1

Converge

24px

Three source nodes of differing weight feed one haloed focal node — many feeds, one filtered view of you.

Distinct: directional + a haloed hero node = a clear "sources→you" story, not a symmetric mesh.
C2

Focus

24px

Sources line up on the left and funnel into one bright node on the right — signal focusing to a point.

Distinct: strict left→right flow reads as a lens/funnel, more purposeful than a scatter graph.
C3

Node-F

24px

The nodes-and-links trace an F — a graph that spells the product. Connections as letterform.

Distinct: tying the network to the F makes it unique to Foresights — but tighter, busier at favicon size.
C4

Orbit

24px

One dominant node at center with satellites orbiting it — you at the core, sources around you.

Distinct: centre-weighted hub flips the story to "you first." Bold, but closest to a generic molecule.
